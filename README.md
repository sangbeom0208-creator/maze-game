# 🧩 미로찾기 (Maze Game)

`index.html` 파일 하나로 동작하는 브라우저 미로찾기 게임입니다. 설치 없이 파일을 브라우저로 열면 바로 플레이할 수 있습니다.

## 기능
- 시작할 때마다 새로운 미로 자동 생성
- 키보드(방향키 / WASD)와 휴대폰 터치(스와이프, 탭)로 이동
- 출구에 도착하면 걸린 시간과 축하 메시지, 난이도별 최고 기록 저장
- 쉬움 / 보통 / 어려움 난이도
- 휴대폰 화면에 꽉 차는 반응형 화면
- 귀여운 양 캐릭터 🐑

## 조작
| 입력 | 동작 |
| --- | --- |
| 방향키 / WASD | 한 칸 이동 |
| N | 새 미로 |
| 스와이프 | 갈림길까지 미끄러져 이동 |
| 탭 | 누른 방향으로 한 칸 이동 |
